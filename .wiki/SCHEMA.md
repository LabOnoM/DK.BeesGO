# Wiki Schema & Ontology Guidelines

This wiki maps the scientific knowledge base of the DK.BeesGO repository. All entries should follow these conventions.

## Folder Directory Structure

- `/sources/`: Raw, unaltered source materials, original papers, or imported READMEs.
- `/entities/`: Unified definitions of biological materials, software tools, databases, or molecules.
- `/system/`: Logs, lessons learned, and metadata.

## Document Naming Conventions

- Entity files must use Title Case: `[[Spatial Transcriptomics]]`, `[[DK.BeesGO]]`.
- Source files must represent their source context: `[[readme]]`.

## Link Requirements

- All key scientific terms must be linked using standard double-bracket wikilinks, e.g., `[[Spatial Transcriptomics]]`.
- Links must build a bidirectional graph to avoid orphan pages.
